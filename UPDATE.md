# Treat-o-Meter Updates Log

## v1.0.0 - The "Sweet" Release 🍦
**Released:** January 11, 2026

### 🚀 Key Features
*   **Gamified Balance System**: Track "Credits" (Rewards) and "Debits" (Punishments) to maintain a healthy habit balance.
*   **Task Manager**:
    *   **Temporary Tasks**: Quick, one-off tasks with optional timers.
    *   **Split Tasks**: High-stakes tasks with both a Reward (success) and Punishment (failure) outcome.
*   **Permanent Habits**:
    *   **Quadrant System**: Track up to 4 Rewards and 4 Punishments daily.
    *   **5-Day Tracker**: Visual streak tracking for your permanent habits.
*   **History & Reports**:
    *   **Monthly Statement**: View all transactions in a clean list.
    *   **PDF Export**: Download professional-looking monthly reports with watermarks.
*   **User Guide**: Built-in guide page with visual explanations of all features.

### 🎨 UI/UX Polish
*   **"Sticker" Aesthetic**: Unique design language featuring high-contrast black text with white outlines (`text-outline-white`).
*   **Animations**:
    *   **Bouncing Loading Screen**: Custom animated logo during app load.
    *   **Interactive Elements**: Hover effects, scale animations, and smooth transitions.
*   **Dark Mode**: Fully supported dark theme that maintains the high-contrast sticker look.
*   **Responsive Design**: optimized for Mobile and Desktop interaction.

### 🔧 Technical
*   **Smart Favicon**: Optimized whitespace removal for larger, clearer browser tab icons.
*   **Firebase Auth**: Secure Google Sign-In integration.
*   **Local Storage Sync**: robust data persistence for tasks and history.
